## ✅ Quick Optimization Checklist

Before uploading an image:

- [ ] Format is JPG (not PNG)
- [ ] Size under 500KB
- [ ] Resolution 800x800px minimum
- [ ] Background is clean/white
- [ ] Product is clearly visible
- [ ] No watermarks (unless branding)

## 📐 Recommended Image Specifications

### Main Product Image

- **Format**: JPG
- **Resolution**: 800x800px or 1024x1024px
- **File Size**: 100-300KB
- **Background**: White or neutral
- **Quality**: 80-85 (JPEG quality setting)

### Gallery Images

- **Format**: JPG
- **Resolution**: 600x600px or 800x800px
- **File Size**: 80-200KB
- **Quality**: 75-80

### Acceptable File Sizes

- Main image: 500KB max
- Gallery image: 300KB max
- System enforces 5MB limit

## 🔄 Step-by-Step: Optimize a Photo

### Using TinyPNG (Easiest)

1. Go to **tinypng.com**
2. Drag your JPG image onto the page
3. Click "Download" (automatically compressed)
4. Upload the smaller file to admin panel
5. Done! Typically 50-70% smaller

### Using Your Phone

1. Take photo of part
2. Use built-in editing app:
   - iOS: Photos app → Edit → Crop to 1:1
   - Android: Google Photos → Edit → Crop
3. Export as JPG
4. Upload directly

### Before Uploading - Desktop

1. Open image in Windows Photos or Preview
2. Right-click → Resize
3. Set to 800x800 or 1024x1024
4. Save as JPG quality 85%
5. Upload

## ⚡ Additional Performance Tips

### 1. Use Consistent Dimensions

- All main images: 800x800px
- All gallery images: 600x600px
- Makes everything load predictably

### 2. Standardize Backgrounds

- White background for all products
- Improves professional appearance
- Easier for customers to compare

### 3. Consistent Lighting

- Bright, even lighting
- No harsh shadows
- Product clearly visible

### 4. Batch Optimization

If you have multiple images:

- FastStone Image Viewer (Windows)
- ImageOptim (Mac)
- Squoosh batch (online)

## 🔒 Quality vs Speed Tradeoff

### Compression Level Recommendations:

| Type            | Format  | Size      | Quality   | Use Case        |
| --------------- | ------- | --------- | --------- | --------------- |
| Maximum Speed   | JPG 75% | 80-150KB  | Good      | Gallery images  |
| Balanced        | JPG 80% | 150-250KB | Excellent | Main product    |
| Maximum Quality | JPG 85% | 250-400KB | Perfect   | High-end/detail |

**Recommendation: Use 80% JPG compression**

- Best balance of quality and speed
- File size 150-250KB
- Suitable for product photos
